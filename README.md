# 癒しのコロニー / Iyashi Colony

> 頭脳はAIへ、感覚は人間へ。— 昼と夜が巡る、小さな村のものがたり

AIと共に生きる自給自足コロニーの構想を、動く絵地図にしたプロジェクトです。
住人たちが村を歩き回り、吹き出しで会話し、空は昼から夕焼け、星の夜、そして朝日へと巡ります。

**デモ:** `index.html` をブラウザで開くだけで動きます（依存ライブラリなし、ビルド不要）。

## 村にあるもの

| エリア | 意味 |
|---|---|
| 畑エリア（5畝） | 食べものを自分たちで育てる |
| AIラボ | 考える仕事はAIに任せる。経済との接続点 |
| 癒しの湯 | 急かされない時間。温泉に浸かるだけでいい |
| 地域との交流所 | 地域にひらかれた小さな市場 |
| みんなのキッチン広場 | 村の心臓。すべての小道はここに集まる |

住人のほかに、猫・犬・猿の親子・鹿・熊（森からひょっこり挨拶する係）と、
ソーラーパネルを積んだEVワゴン（日本の本来の姿を探す旅の相棒）が暮らしています。

## 構想の背景

このコロニーは、次の順番で育っていく想定です。

1. **土台** — AIが好きな仲間と、AIで能力を拡張して経済的・生活的な土台を作る
2. **環境** — 畑・動物・温泉のある、柔らかな空気の癒しの環境を整える
3. **回復のグラデーション** — 深く休む → 場を明るくする → やりたいことへ。役割は固定しない

「治そうとしなくても、治っていく場所」がコンセプトです。

## 技術メモ

- 素のHTML + SVG + JavaScript（フレームワーク・ビルドなし）
- 3D版キャラクター: [KayKit Character Pack: Adventurers](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0) by Kay Lousberg（CC0・クレジット不要ですが感謝を込めて記載）
- 昼夜サイクル：空の色をキーフレーム補間、太陽と月が弧を描いて移動、夜は星・窓明かり・焚き火の輝き
- 住人：ウェイポイント巡回 + 到着時に吹き出しで発話
- フォント：[Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic)
